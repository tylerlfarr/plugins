# Operator path: Import → Resolve → Check → Review

Short routine workflow. Owner source activation is separate (Sources tab).

1. **Import** — Upload the workbook on Import (hosted: file upload; store shortcut only when present). Confirm preview sections, then commit.
2. **Resolve** — On Permits / Attention: fill missing property identity, confirm property before contacts, confirm jurisdiction when the AHJ is known. Changing jurisdiction clears prior confirmation.
3. **Check** — After owner has activated the Fairfax PLUS source, confirm Fairfax jurisdiction on eligible rows, then **Check source** or **Run Fairfax checks**. Unsupported AHJs return unavailable/blocked honestly.
4. **Review** — Attention list + structured export. Export uses the **same q + filters** as the table (filtered-row). Use **Export selected** only for checked rows.

Do not treat table search as county discovery. Do not Save a stale detail after bulk/import without resolving the conflict banner.
